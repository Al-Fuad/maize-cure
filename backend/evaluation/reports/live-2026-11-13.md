# Maize Cure — live LLM protocol evaluation

Completed 13 November 2026 (Asia/Dhaka). Local live evaluation; not deployed.

## Method

17 fixed cases × 5 modes = 85 advisory results: rules, three single providers and minimum-two-model consensus. Four classes × English/Bengali × 0.95/0.60 confidence, plus an ambiguous two-disease case. One repetition; caches cleared. Healthy care is static and makes no provider calls.

## Results

Latency is end-to-end for the 13 non-Healthy single-provider cases, including retry/fallback overhead. Healthy responses are excluded. JSON counts include provider attempts from both single and consensus modes.

| Provider / model | Usable single-model advice | Median | P95 | Valid JSON attempts | Retries |
|---|---:|---:|---:|---:|---:|
| gemini / `gemini-3.5-flash-lite` | 12/13 | 1.640 s | 3.413 s | 23/30 | 4 |
| groq / `openai/gpt-oss-120b` | 13/13 | 0.966 s | 1.143 s | 26/26 | 0 |
| openrouter / `nvidia/nemotron-3.5-lightning:free` | 13/13 | 1.248 s | 4.358 s | 26/27 | 1 |

Consensus succeeded in **13/13** non-Healthy cases, median **1.463 seconds**, without rule-based fallback. Gemini alone fell back once following HTTP 503. There were 83 provider attempts including five retries.

## Guardrail checks

Chemical-category advice was absent in all 55 low-confidence/ambiguous/Healthy results. All 5 ambiguous cases carried a warning and failed confidence validation. There were no application-cache hits and zero discarded out-of-protocol items recorded in this run. These are software/protocol checks, not proof of agronomic correctness.

## Diagnostic and correction

The partial run live-2026-11-13-01 was intentionally interrupted and marked diagnostic. A metadata probe found Nemotron returned finish_reason=length, 2,048 reasoning tokens and no final content. The adapter now disables reasoning for the exact Nemotron default and sets Groq GPT-OSS reasoning effort to low. The complete run restarted from case one and does not pool partial diagnostic data. The 2,048 output cap is unchanged.

Settings references: [OpenRouter reasoning](https://openrouter.ai/docs/guides/best-practices/reasoning-tokens), [Groq reasoning](https://console.groq.com/docs/reasoning).

## Interpretation and limits

Groq was the fastest single-provider option in this small run. Multi-model consensus remained available when a provider failed. This is one run on limited fixed cases, not a definitive model ranking or uptime guarantee.

English/Bengali cases use the same English selection prompt; Bengali display text comes from stored protocol translations. This does not benchmark LLM translation. Constrained selection is not comparable to the paper’s free-form correct-cure/dosage rubric. No field trial, classification accuracy measurement or expert agronomic review was performed. Expert-review.csv remains unscored.
